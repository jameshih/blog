## Installation

Requires [Node.js 10](https://formulae.brew.sh/formula/node@10).

```
$ cd ethtereum-slot-machine
$ npm i
```

## Interacting with the contract

Use the OpenZeppelin console.

For local deployment, make sure you start a local Ganache network.

```
$ npx ganache-cli -p 8545
$ npx oz init
$ npx oz compile
$ npx oz create
```

[View the contract on Etherscan](https://rinkeby.etherscan.io/address/0xe253bba5e2b71960b0b7328d04b8480b16a00706).
