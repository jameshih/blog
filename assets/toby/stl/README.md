# Toby's original STL models

These are byte-for-byte copies of the seven model URLs encoded in the original Toby article's GitHub solid embeds. All originals belong to James Shih's Virtual-Robotics repository at commit `c1e94f7eff626c218e73162bd1c1a5e374654b01`.

`manifest.json` maps each article caption/local filename to its pinned original URL, byte length, binary triangle count and SHA-256 checksum. Filenames are simplified locally; file contents are unchanged. The viewer rotates Z-up geometry and normalizes its units in memory only. Downloads always return the original STL bytes.
